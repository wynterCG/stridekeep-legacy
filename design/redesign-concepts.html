WHAT v2 GOT WRONG

Tried to fix monotony with shape variety. Result: corner brackets + ornate medallion + 2×2 grid + ornament divider + nested CTA box all competing. Six "look at me" elements = no hero.

v3 PRINCIPLE

Hierarchy via emphasis, not via shape variety. The town illustration is the only loud thing. Everything else stays intentionally quiet so the eye knows where to land.

CTA INSIDE THE HERO

$340 set in 34px Playfair italic — the largest number on the screen. No nested box, no border. Just typography. Brass progress bar below ties it back to the illustration.

INFO STRIP · NOT A GRID

"8,420 STEPS · $2/STEP · +$340 TODAY" — one centered line of typography with brass dot separators. Replaces the dial and the 2×2 stat tiles. Lighter, easier to scan.

CASES · UNIFORM ROWS

Same shape, same height. Differentiated by left-bar color, medallion glow halo, and bar-fill treatment (luxury gets a brass gradient, premium gets cool blue, starter gets brass). They read as a set with detail variation, not three competing cards.

LIVING TOWN STAYS

The hero illustration is the keeper. As milestones unlock, more buildings render solid; the next stays ghosted with the "NEXT" arrow. This is what makes Home yours.

WHAT'S WRONG TODAY

Both lines hug the bottom for 90% of the visible window because cumulative-since-window starts at $0 and bots only just woke up. The chart looks empty most of the time. Y-axis has gridlines but no labels. Footer crams "+$X · Total: $Y · $Z · +$W" in one strip — confusing.

ALT A · KEEP THE LINE

Auto-scale time window to start at first deposit (fills width). Add Y-axis $-labels (right-anchored). Add X-axis time markers (1H · 30M · 15M · NOW). Bigger lead callout in 22pt Playfair italic. Cleaner foot — RED/BLUE separated, no run-together totals.

ALT B · TUG OF WAR

One bar across the card. RED fills left of center, BLUE fills right of center. The brass marker sits at the lead point — slides left when RED leads, right when BLUE leads. Mini sparkline below shows "lead over time" trend. Zero chart literacy needed; readable in 0.5s glance.

ALT C · TWIN GAUGES

Two thermometer-style fills side-by-side. Each gauge shows that team's last-hour cumulative as a height. Tick marks at 15m/30m/45m back. Visceral "who's bigger" comparison. Lead chip in the header.

PERFORMANCE COST

All three options remove the SVG-area-path computation, which means simpler render code and no more "auto-scale vMax" math. Tug + gauges are CSS-only (no SVG at all). Alt A keeps SVG but with simpler, fixed gridlines.

RECOMMENDATION

If you want the rivalry to land in 0.5s during a walk → Alt B (Tug of War). If you want trend-over-time visible → Alt A. If you want the most dramatic / "race to the top" feel → Alt C.
